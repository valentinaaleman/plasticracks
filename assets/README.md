# Art & Design Team — Asset Guidelines 🎨

Welcome! This folder is where all visual assets (photos, 3D renders, diagrams, logos, and icons) for the **Plastiracks** website live.

Please follow these simple guidelines so your designs look sharp on the website and load fast for customers on both mobile phones and laptops.

---

## 📁 Folder Structure

```
assets/
├── media/        <-- Photos, 3D renders, warehouse shots, banners, and hero graphics
└── icons/        <-- Vector icons, logos, trust badges, and UI symbols
```

* **Go to [media/](media/)** for: Product photographs, 3D system renders, warehouse action shots, facility photos, and background banners.
* **Go to [icons/](icons/)** for: Brand logos, certification seals, UI symbols, material badges (e.g. HDPE, FDA, Recyclable).

---

## ⚡ 3 Golden Rules for Naming Files

Computers and web browsers can break or show broken image links when file names have spaces, accents, or special characters.

### 1. Always use lowercase letters
* ✅ `rack-modular-blue.webp`
* ❌ `Rack-Modular-Blue.webp`

### 2. Use hyphens (`-`) instead of spaces
* ✅ `cooler-cart-transport.jpg`
* ❌ `cooler cart transport.jpg`
* ❌ `cooler_cart_transport.jpg`

### 3. Be descriptive (No camera defaults)
* ✅ `hero-warehouse-racks.webp`
* ❌ `IMG_3849.JPG`
* ❌ `render_final_v2_edit(1).png`

## 📐 Recommended File Formats & Sizes

| Asset Type | Best Format | Max File Size | Why |
| :--- | :--- | :--- | :--- |
| **Photos & 3D Renders** | `.webp` (or `.jpg`) | Under **400 KB** | Keeps the site fast on mobile networks |
| **Transparent Product Cutouts** | `.webp` or `.png` | Under **500 KB** | Clean transparent background without gray boxes |
| **Icons & Badges** | `.svg` (vector) | Under **50 KB** | Stays crystal clear at any zoom level |

> 💡 **Quick Tip for Free Image Compression:**  
> Before dropping large camera photos or render exports here, run them through [https://tinypng.com](https://tinypng.com) or [https://squoosh.app](https://squoosh.app) to reduce file size without losing quality.

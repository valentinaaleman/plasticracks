# Icons, Logos & Badges Folder 🏷️

Drop all **logos**, **vector icons**, **certification seals**, and **trust badges** here.

---

## 🎨 Recommended Formats & Requirements

* **Primary Format: `.svg` (Vector)**  
  SVGs are preferred because they never get blurry or pixelated, look razor sharp on Retina/4K displays, and have tiny file sizes (usually under 15 KB).
* **Secondary Format: `.png`**  
  If `.svg` is unavailable, export a transparent `.png` at `2x` resolution so it looks clean on mobile phones and laptops.
* **Background:** Always ensure the background is **transparent** (no white or checkered boxes around the icon).

---

## 🏷️ Standard Naming Convention

Please name your files using these prefixes:

### 1. Brand Logos (`logo-...`)
* `logo-plastiracks-dark.svg`
* `logo-plastiracks-white.svg`
* `logo-plastiracks-symbol.svg`
* `favicon.svg`

### 2. Feature & UI Icons (`icon-...`)
* `icon-modular-rack.svg`
* `icon-mobile-cart.svg`
* `icon-freezer-temperature.svg`
* `icon-washdown-spray.svg`
* `icon-forklift-impact.svg`
* `icon-recyclable-loop.svg`

### 3. Certification & Trust Badges (`badge-...`)
* `badge-fda-approved.svg`
* `badge-nsf-sanitary.svg`
* `badge-hdpe-recyclable.svg`
* `badge-100-rustproof.svg`
* `badge-iso-certified.svg`

---

## 📐 Standard Sizes

| Asset Type | Target Canvas Size | File Format |
| :--- | :--- | :--- |
| **Small UI / Bullet Icons** | `24 × 24 px` or `32 × 32 px` | `.svg` |
| **Feature Card Icons** | `48 × 48 px` or `64 × 64 px` | `.svg` |
| **Trust Badges & Seals** | `80 × 80 px` to `120 × 120 px` | `.svg` or `.png` |
| **Full Header Logo** | `240 × 60 px` (flexible) | `.svg` |

# Media & Photography Folder 📸

Drop all **photos**, **3D renders**, **hero backgrounds**, and **application shots** here.

---

## 🎯 Recommended Image Dimensions

Using these pixel dimensions ensures your graphics fit the website cards and banners without stretching or getting cropped awkwardly:

| Image Use | Recommended Dimensions | Aspect Ratio | Target File Size |
| :--- | :--- | :--- | :--- |
| **Hero / Main Banners** | `1920 × 1080 px` | 16:9 | Under **400 KB** |
| **Product Showcase Cards** | `1200 × 900 px` | 4:3 | Under **250 KB** |
| **Product Cutout (Transparent)** | `1000 × 1000 px` | 1:1 Square | Under **300 KB** |
| **Industry / Solution Photos** | `1200 × 800 px` | 3:2 | Under **250 KB** |

## 💡 Best Practices for Exporting
1. **Format:** Export as **`.webp`** whenever possible. If `.webp` is not available in your software (Illustrator / Photoshop / Blender / Canva), export as high-quality **`.jpg`** (or **`.png`** if you need transparent backgrounds).
2. **Color Profile:** Always export in **sRGB** (Standard RGB). Do NOT export in CMYK (CMYK is for printing on paper and will look discolored in web browsers).
3. **No Watermarks / Placeholder Text:** Keep source files clean of draft watermarks.
